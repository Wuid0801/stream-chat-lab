# 수동 확인 목록

자동화하기 어려운 항목이다. 키 판별 로직(`apps/web/src/chat/keys.ts`)은 단위 테스트로 확인하고, 실제 입력기 동작은 아래 목록으로 확인한다.

실행: `yarn dev` → http://localhost:5173

## IME (한글 입력)

각 환경에서 "안녕하세요"를 입력하고, 마지막 글자 조합이 끝나기 전에 Enter를 누른다.

| 환경                         | 기대 결과                                             | 확인 |
| ---------------------------- | ----------------------------------------------------- | ---- |
| Windows + Chrome + MS 입력기 | 첫 Enter는 조합 확정만 한다. 두 번째 Enter에 전송된다 | [ ]  |
| Windows + Edge + MS 입력기   | 위와 같다                                             | [ ]  |
| macOS + Chrome + 기본 입력기 | 위와 같다                                             | [ ]  |
| macOS + Safari + 기본 입력기 | 위와 같다. 마지막 글자가 잘리지 않는다                | [ ]  |
| iOS Safari                   | 위와 같다                                             | [ ]  |
| Android Chrome + Gboard      | 위와 같다                                             | [ ]  |

공통 확인

- [ ] 전송된 메시지의 마지막 글자가 잘리지 않는다.
- [ ] 같은 메시지가 두 번 전송되지 않는다.
- [ ] Shift+Enter는 줄바꿈이다.

## 시나리오 녹화 (README GIF)

| URL                                    | 확인할 것                               |
| -------------------------------------- | --------------------------------------- |
| `/?scenario=normal&seed=11`            | 보낸 즉시 표시 → 토큰 스트리밍 → 확정   |
| `/?scenario=done-only&seed=11`         | 콘솔에 계약 위반 경고, 화면은 정상 완료 |
| `/?scenario=close-after-final&seed=11` | 오류 표시 없음                          |
| `/?scenario=drop-after-saved&seed=11`  | 오류 표시 없이 완료                     |
